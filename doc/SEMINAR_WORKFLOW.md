# Seminar Workflow

Ovaj folder je predvidjen za dokumentaciju projekta i tekst seminarskog rada.

Preporuceni sadrzaj seminarskog rada:

1. Uvod u visekriterijsku optimizaciju
2. NSGA-II algoritam
3. Reprezentacija CNN hiperparametara kao genoma
4. Odabir dataseta i train/validation/test split
5. Definicija ciljnih mjera
6. Tok izvrsavanja algoritma
7. Analiza Pareto fronta
8. Zakljucak i moguca prosirenja

U Streamlit interfejsu sada se mogu direktno demonstrirati:

- izbor dataseta
- izbor split-a
- broj instanci po splitu
- izbor mjera optimizacije
- tok izvrsavanja algoritma
- Pareto-optimalna rjesenja
